# Project Structure

- `app/engine.py` — evidence normalization, canonical commitments, reconciliation and temporal states
- `app/agent.py` — grounded question answering / agent boundary
- `app/main.py` — FastAPI service
- `static/` — polished dashboard UI
- `data/source_data.json` — transcribed assignment data pack, no external business facts
- `tests/` — API and engine tests
- `docs/` — architecture, assumptions, demo, evaluation and AI-use notes
- `AIONOS_Executive_Productivity_Agent.pptx` — required 10-slide deck
